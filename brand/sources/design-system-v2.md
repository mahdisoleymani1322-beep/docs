# 4. Brand Design Principles

## 4.1 Strategic Calm

طراحی نباید برای جلب توجه فریاد بزند.  
قدرت بصری از نظم، فضای خالی، تایپوگرافی، نسبت‌ها و کنتراست ایجاد می‌شود.

## 4.2 Intelligent Minimalism

هر عنصر باید دلیل داشته باشد.  
اگر یک خط، آیکون، Glow، Card یا Decoration اطلاعات یا سلسله‌مراتب ایجاد نمی‌کند، حذف شود.

## 4.3 Execution Over Decoration

ظاهر سیستم باید حس «قابل اجرا بودن» بدهد.

ترجیح داده شود:

- Workflow
- KPI
- Timeline
- Process
- Dashboard
- Roadmap
- Before / After
- Problem / Solution
- Formula
- Data

به‌جای:

- Abstract AI decorations
- Random glowing shapes
- Generic futuristic visuals

## 4.4 Human + AI

AI باید در کنار تصمیم‌گیری، تیم، کسب‌وکار، داده یا فرآیند نشان داده شود.

از تصویرسازی «ربات به‌عنوان AI» استفاده نشود مگر در یک محتوای آموزشی که موضوع مستقیماً درباره رباتیک باشد.

## 4.5 Premium Through Restraint

Premium بودن با استفاده زیاد از Accent، Shadow، Blur یا Effect ایجاد نمی‌شود.

Premium بودن باید از این موارد بیاید:

- Typography
- Alignment
- Spacing
- Whitespace
- Precise composition
- Controlled color
- High-quality imagery

# 8. Color Usage Ratios

Light Mode حالت پیش‌فرض سیستم است و باید در بیشتر خروجی‌ها استفاده شود:

- 70–82% Soft White `#FDFDFD`
- 8–15% Warm Cream `#F0EBE5`
- 4–8% Light Teal `#9AD9D5` و Soft Sand `#D9D1C9` برای کارت‌ها، خطوط و سطوح نرم
- 3–6% Deep Navy `#051939` برای تیتر، متن و کنتراست
- 2–5% Mahdiyar Teal `#059B9A` برای عناصر فعال و هویت برند
- 0–3% Medium / Deep Teal برای تأکید محدود، KPI و وضعیت مثبت

Dark Mode حالت ثانویه است و فقط برای سکشن‌های محدود، اسلایدهای بیانی یا نقاط کنتراست استفاده شود:

- 70–80% Deep Navy `#051939`
- 12–18% Soft White / Warm Cream
- 4–8% Mahdiyar Teal
- 0–4% Medium / Light Teal

**Orange, Gold and warm Yellow accents are not part of the Mahdiyar palette and should not be introduced as brand colors.**

---

# 9. Color Pairing Rules

## Approved

- Deep Navy on Soft White
- Deep Navy on Warm Cream
- Soft White on Deep Navy
- Mahdiyar Teal on Soft White for active elements
- Deep Navy on Light Teal for highlighted cards
- Mahdiyar Teal + Light Teal for data connections and soft emphasis
- Deep Teal on Soft White for positive result states
- Charcoal Gray on Soft White / Warm Cream for body copy

## Avoid

- Orange, Gold or warm Yellow brand accents
- Teal long paragraphs
- Using several teal shades at equal visual weight
- Deep Teal as decorative UI without semantic reason
- Gradient-heavy backgrounds
- Purple / pink / blue cyber gradients
- dominant orange
- random pastel palettes outside the approved palette

# 17. Typography Rules

- Headings must be short, sharp, and confident.
- Avoid long paragraphs inside visuals.
- Large numbers are encouraged for metrics, years, steps, results and project counts.
- Metadata should be small and aligned precisely.
- Do not use decorative, handwritten, playful, soft or luxury-fashion fonts.
- Do not center long Persian paragraphs.
- Use bold only for hierarchy, not for entire paragraphs.
- Do not mix more than two font families in one output.
- Do not use all caps for long English phrases.

# 22. Whitespace

Whitespace is a functional brand element.

Use large empty areas to create:

- clarity
- focus
- premium feeling
- hierarchy
- strategic calm

Do not fill blank areas only because they look empty.

Whitespace can occupy more than 40% of a composition when the content is strategic or statement-driven.

---

# 23. Shape Language

Primary:

- Rectangle
- Square
- Thin line
- Precise circle for nodes / data only

Corner behavior:

- Sharp corners preferred
- Maximum subtle radius only for UI surfaces

Recommended radius:

- 0 px for editorial / slide layouts
- 4 px for technical UI
- 8 px maximum for friendly web cards

Avoid:

- pill-shaped everything
- playful blobs
- organic random shapes
- rounded cards with large 24–40 px radius unless a specific interface requires it

---

# 24. Borders

Default:

- 1 px
- Soft Sand on light mode
- White 12–20% on dark mode

Use borders to define structure, not decoration.

Heavy borders should only appear in:

- comparison layouts
- CTA emphasis
- problem / solution separation

---

# 25. Shadows

Default: no shadow.

Allowed:

- extremely subtle shadow for floating website UI
- dashboard preview on light background
- elevated modal or prompt panel

Avoid:

- soft large startup shadows
- blue glow shadow
- card shadows on every component
- fake 3D depth

---

# 26. Motion

Motion should feel precise and intentional.

Preferred:

- fade
- masked reveal
- vertical / horizontal slide
- line drawing
- number count
- node connection
- chart build
- subtle scale 98% → 100%

Avoid:

- bounce
- elastic
- spinning
- excessive parallax
- neon flicker
- playful spring movement

Recommended duration:

- Micro interaction: 120–180 ms
- UI transition: 180–260 ms
- Slide visual reveal: 300–600 ms

# 29. RTL / LTR Rules

## Persian RTL

- Main alignment: Right
- Headline anchor: right edge
- Metadata: right or top-right
- Process flow: right-to-left unless timeline logic requires otherwise
- Arrow direction must follow reading logic
- Chart axes remain mathematically correct, not mirrored without reason

## English LTR

- Main alignment: Left
- Headline anchor: left edge
- Metadata: left or top-left
- Process flow: left-to-right

## Mixed Persian + English

English labels can remain LTR inside RTL layouts.

Examples:

`AI STRATEGY`
`نقشه راه هوش مصنوعی`

Do not mirror English words character-by-character.

# 33. Photography Treatment

# 38. Data Visualization

Charts must feel like scientific / executive instruments.

- use thin axes
- keep labels minimal

- Medium Teal for one key insight only
- Deep Teal only for positive status / result

- avoid legends when direct labels are clearer

# 39. Line Chart

# 40. Bar Chart

- flat bars
- low radius or square
- one focal bar can be Mahdiyar Teal
- Medium Teal can identify one exceptional business insight
- avoid rainbow categories

---

# 41. Donut / Pie

Use only when:

- categories are 2–5

Avoid for:

- more than 5 categories
- precise comparison
- decorative dashboards

# 119. Visual Review Questions

A design should be rejected or revised if the answer to any of these is “No”:

- Does this look like Mahdiyar?
- Does the design communicate business value before visual novelty?
- Can the viewer identify the main message in a few seconds?
- Is AI represented as a tool for real work?
- Is the layout calm enough?
- Is the hierarchy strong enough?
- Is the design credible for a CEO or business owner?
- Could this design still work if all unnecessary decorations were removed?
- Does every accent color have a purpose?
- Is the output executable, not merely inspirational?
