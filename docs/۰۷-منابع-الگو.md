# ۰۷ — منابع الگو

این سند می‌گوید هر تصمیم معماری از کجا آمده و **سطح شاهد** آن چیست، تا هیچ الگویی بی‌منبع وارد سیستم نشود.

سطح شاهد:
- **الف:** کد یا متن منبع مستقیماً خوانده شد (مسیر دقیق آمده است)
- **ب:** مستندات رسمی خوانده شد
- **ج:** فقط توضیح عمومی ریپو یا مقاله دیده شد و کد بررسی نشد

تاریخ بررسی همه‌ی منابع: ۲۹ سپتامبر ۲۰۲۶.

## ۲. arkan-ai-course (سطح الف)

ریپوی عمومی [`siavash-smf/arkan-ai-course`](https://github.com/siavash-smf/arkan-ai-course): دوره‌ی فارسی شش
هفته‌ای روی یک کلاینت فرضی. نمونه‌ی پروپوزال آرکان که راهنمای پرپوزال نقدش کرده (فصل ۶) از همین دوره است.

| الگو | مسیر در آن ریپو | در این پروژه |
|---|---|---|
| ارکستریتور کد است، نه LLM | `docs/۰۶-هفته-سنجش.md` (تصمیم ۱)؛ `docs/راهنمای-ایجنت‌ها.md` (جمع‌بندی) | اسکیل با مراحل ثابت + `gate.py` + `loop.py` |
| نویسنده و ویراستار جدا، حلقه با آستانه و سقف دور | `docs/راهنمای-ایجنت‌ها.md` (بخش ۵ و «حلقه‌ی بازبینی») | Loop اصلی L4 |
| کار قطعی با کد، نه مدل | `docs/۰۶-هفته-سنجش.md` (تصمیم ۲)؛ `apps/۰۳-استودیوی-محتوا/src/lib/agents/seo-checks.ts` | `checks.py` |
| چند داور مستقل وزن‌دار | `docs/۰۶-هفته-سنجش.md` (تصمیم ۳) | سه داور: روبریک، ادعا، رد فوری |
| گلدن‌ست در گیت، نه در دیتابیس | `docs/۰۶-هفته-سنجش.md` (بخش گلدن‌ست) | `evals/golden/` قفل |
| داور هم ارزیابی شود: کاپای کوهن، آستانه ۰٫۶ | `docs/۰۶-هفته-سنجش.md` (متا-ارزیابی)؛ `apps/۰۵-سنجش/src/lib/alignment.ts` | `kappa.py`، Loop کالیبراسیون L5 |
| حلقه‌ی درس: ≤۳ درس در هر اجرا، سقف ۸ درس فعال برای هر ایجنت، ≤۵ درس در هر پرامپت | `docs/راهنمای-ایجنت‌ها.md` (بخش ۸) | critic + `lessons.py` |
| human-in-the-loop در معماری، نه در نیت | `README.md` آن ریپو (درس ۸) | بالاترین وضعیت «آماده‌ی بررسی انسان» |
| هر ایجنت یک شغل + قرارداد خروجی JSON + یک retry | `docs/راهنمای-ایجنت‌ها.md` (بخش مشترک) | schema برای هر خروجی + retry یک‌باره |

**آنچه عمداً برداشته نشد:**

| مورد | دلیل |
|---|---|
| تنظیم دمای مدل برای داورها | subagentهای Claude Code فیلد temperature ندارند ([مستندات](https://code.claude.com/docs/en/sub-agents)). جایگزین: نقل‌قول اجباری، سقف‌های قطعی و کالیبراسیون κ |
| PDF تصویری در مرورگر | خود درس آرکان می‌گوید «متن PDF تصویر است و قابل جست‌وجو نیست»؛ راهنمای پرپوزال متن قابل انتخاب می‌خواهد (فصل ۸) |
| انتشار خودکار بالای آستانه | در آرکان، ناشر بالای ۷۵ خودکار منتشر می‌کند؛ در این پروژه هیچ ارسالی نیست |

## ۳. arkan-crm: بخش پروپوزال و قرارداد (سطح الف)

ریپوی [`siavash-smf/arkan-crm`](https://github.com/siavash-smf/arkan-crm). طبق `CLAUDE.md` ریپوی دوره، پوشه‌ی
`apps/۰۴-crm` آینه‌ی آن است و خوانش از همان آینه انجام شد.

| الگو | مسیر | در این پروژه |
|---|---|---|
| یک داده‌ی ساخت‌یافته، تنها منبع رندر | `src/lib/crm/proposals/types.ts` (`ProposalData`) | `document.json` → `render.py` |
| سند = فهرست بلوک‌های اتمی، جدا از نمایش | `src/lib/crm/proposals/blocks.ts` | بلوک‌های `para`، `list`، `table`، `callout`، `ref` |
| چرخه‌ی وضعیت و شماره‌ی نسخه | `types.ts` (`ProposalStatus`، `sendRevision`) | `doc.lifecycle` + `revision` |
| «درخواست تغییر» نسخه‌ی تازه می‌سازد | `آموزش/از-پروپوزال-تا-قرارداد.md` (جریان کار) | بازخورد `request_changes` ← اجرای تازه با revision+1 |

قالب‌های قیمت ثابت آرکان (`templates.ts`) برداشته نشد: راهنمای پرپوزال می‌گوید «قیمت نمونه آموزشی، قیمت بازار یا
قیمت پروژه جدید نیست».
